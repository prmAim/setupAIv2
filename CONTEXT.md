# Контекст setupAIv2

## Главная цель

Согласовано владельцем 27.11.2026. Это основной ориентир для планирования,
выбора архитектуры, реализации и оценки готовности проекта.

**Issue → план → изменение кода → проверки → исправление или остановка → доказательства → PR → проверка PR → слияние в `main` → следующая Issue.**

Агент выполняет цикл самостоятельно, включая ночью, соблюдая согласованные условия проверок и слияния.

setupAIv2 должен обеспечивать автономное выполнение этого цикла: агент сам
берёт готовую задачу из GitHub Issues, доводит её до результата и переходит
к следующей без ручной передачи между этапами, в том числе пока владелец спит.
Первый целевой проект — `prmAim/orbita`; затем подключаются другие проекты.
Цикл продолжается, пока есть доступные для выполнения задачи и соблюдены
согласованные условия работы. При остановке сохраняются причина и прогресс.

Слияние выполняется после проверки PR по согласованной политике допуска.
Промежуточные этапы с проверкой человеком служат приёмке отдельных частей
системы. Их завершение не означает достижение всей главной цели.

## Сохранение задачи и прогресса

Исполнительная среда должна сохранять исходную Issue, цель, принятые решения,
план, выполненные шаги, результаты проверок, доказательства, состояние PR
и следующий шаг. После прерывания работа продолжается из сохранённого состояния
без повторного объяснения задачи владельцем и без дублирования внешних действий.
Состояние и память разных проектов должны быть разделены.

## Выбранная исполнительная среда

**Выбран DeerFlow Runtime Harness как общая исполнительная платформа
для Fortune и Orbita.** Решение подтверждено владельцем 27.11.2026.

Причины выбора, рассмотренная собственная реализация
на LangGraph + LangChain + Pydantic + Langfuse, границы интеграции и порядок пересмотра зафиксированы в
[ADR-0001](docs/adr/0001-deerflow-runtime.md). Прочитай его перед обсуждением
архитектуры или выбором следующего этапа реализации.

Работу продолжаем в рамках этого решения. Сама установка среды не является
приёмкой полного автономного цикла.

При продолжении работы сверяй их с этой целью. Менять главную цель следует
только по явному решению владельца.
