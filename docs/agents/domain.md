# Domain docs

## Структура

Репозиторий использует single-context:

- `CONTEXT.md` в корне — предметные понятия и словарь.
- `docs/adr/` — архитектурные решения.

## Чтение перед изучением кодовой базы

Прочитай корневой `CONTEXT.md` и ADR, относящиеся к текущей задаче.

Если документы отсутствуют, продолжай работу без замечаний
об их отсутствии и без предложения создать их заранее.
Навык domain-modeling создаёт их по мере уточнения понятий
и принятия решений.

## Терминология

В задачах, предложениях по рефакторингу, гипотезах и тестах
используй термины из `CONTEXT.md`.

Если нужного понятия нет, проверь, соответствует ли оно языку
проекта. Реальный пробел отмечай для domain-modeling.

## Конфликты решений

Если предложение противоречит существующему ADR, явно укажи
номер решения, суть противоречия и причину пересмотра.
