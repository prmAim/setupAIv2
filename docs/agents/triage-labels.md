# Triage labels

| Каноническая роль | Метка GitHub | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется первичная оценка задачи |
| needs-info | needs-info | Ожидаются дополнительные сведения от автора |
| ready-for-agent | ready-for-agent | Задача полностью описана и готова к автономной работе агента |
| ready-for-human | ready-for-human | Реализация требует участия человека |
| wontfix | wontfix | Задача не будет выполняться |

Когда навык ссылается на каноническую роль, используй метку
из второго столбца. При смене словаря обновляй этот столбец.
