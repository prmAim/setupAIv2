# DeerFlow Runtime Harness как общая исполнительная платформа

Выбрана общая платформа **DeerFlow Runtime Harness для Fortune и Orbita**.
Решение согласовано владельцем 26.11.2026 и явно подтверждено 27.11.2026.
Используем готовые механизмы агента, делегирования, инструментов, контекста,
памяти и песочниц, чтобы сосредоточить собственную разработку на полном
автономном цикле, определённом в [CONTEXT.md](../../CONTEXT.md).

## Рассмотренная альтернатива

Собственная исполнительная среда на LangGraph + LangChain + Pydantic + Langfuse
рассматривалась до выбора DeerFlow. Созданные прототипы и проверки остаются
материалом для интеграции; их наличие не отменяет выбранную архитектуру.
DeerFlow использует LangGraph и LangChain, поэтому библиотеки могут оставаться
в решении. Langfuse сохраняет роль наблюдаемости.

## Границы решения

- У Fortune и Orbita отдельные настройки агентов, память, доступы и контейнерные
  рабочие пространства. Общими могут быть проверенные инструменты и универсальные навыки.
- TENDIS используется только для сравнения, подключение к платформе не согласовано.
- Собственная интеграция обеспечивает работу с Issues, проверки, доказательства,
  публикацию PR, проверку PR, слияние и переход к следующей задаче.
- Сохранение задачи, решений и прогресса и восстановление после прерывания —
  требования к приёмке выбранной платформы, а не гарантия от одного факта установки.
- Подключение Codex через подписку остаётся вопросом интеграции. Трудности
  авторизации или оплаты API сами по себе не меняют выбор исполнительной среды.

## Продолжение работы и пересмотр

DeerFlow v2.2.0 установлен; сведения об установке находятся в
[инструкции эксплуатации](../../infra/deerflow/README.md).
Готовность полного автономного цикла должна подтверждаться отдельно.

Продолжать проект следует от выбранной платформы и существующих результатов.
Предложение перейти к ручной работе в Codex или к собственной исполнительной
среде является предложением пересмотреть этот ADR. Изменение выбранного пути
требует явного решения владельца с обновлением ADR и CONTEXT.md.
Промежуточный MVP и исторические задачи интерпретируются в рамках главной цели
и этого решения.
