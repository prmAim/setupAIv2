# Repository instructions

## Agent skills

### Issue tracker

Задачи и спецификации ведутся в GitHub Issues репозитория
prmAim/setupAIv2. Перед чтением, созданием или изменением задач
прочитай `docs/agents/issue-tracker.md`.

### Triage labels

Используются пять стандартных triage-меток. Перед классификацией
задач прочитай `docs/agents/triage-labels.md`.

### Domain docs

Используется single-context: корневой `CONTEXT.md` и `docs/adr/`.
Перед изучением кодовой базы прочитай `docs/agents/domain.md`.
