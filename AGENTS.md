# Repository instructions

## Главная цель и восстановление контекста

Перед началом работы в новом чате и после сокращения или потери контекста
обязательно прочитай [CONTEXT.md](CONTEXT.md): там зафиксированы главная цель,
полный автономный цикл и требования к сохранению прогресса.
Затем прочитай [ADR-0001](docs/adr/0001-deerflow-runtime.md) о выбранной
исполнительной платформе DeerFlow и условиях пересмотра этого решения.
Перед предложением следующего шага сопоставь текущий этап с полным циклом;
при отчёте о готовности явно укажи, какая часть цели подтверждена.

## Agent skills

### Issue tracker

Задачи и спецификации ведутся в GitHub Issues репозитория
prmAim/setupAIv2. Перед чтением, созданием или изменением задач
прочитай `docs/agents/issue-tracker.md`.

### Triage labels

Используются пять стандартных triage-меток. Перед классификацией
задач прочитай `docs/agents/triage-labels.md`.

### Domain docs

Используется single-context: корневой `CONTEXT.md` и `docs/adr/`.
Перед изучением кодовой базы прочитай `docs/agents/domain.md`.
